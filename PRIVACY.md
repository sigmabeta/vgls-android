# VGLeadSheets Android App Privacy Policy

The app counts how many sheets the user has seen and keeps track of which ones. This data is stored
locally and is never sent to any server. Using this data, the app can recommend sheets to users.
This data may be deleted at any time from the settings menu.

# Third-party services

- When the user visits a screen in the VGLeadSheets app, information about that screen visit is sent
  to Firebase Analytics. This collection is governed
  by [Google's Privacy Policy](https://support.google.com/analytics/answer/7318509?hl=en).
- If the user crashes, information about that crash is sent to Crashlytics. This collection is
  governed by [Crashlytics' Privacy Policy](https://firebase.google.com/support/privacy).
